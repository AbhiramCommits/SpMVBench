# SpMVBench benchmark results

GPU: **Tesla T4** (sm_75). Assumed theoretical peak bandwidth: **320 GB/s** (vendor spec assumed from the device name). Achieved bandwidth uses the no-reuse traffic model.

MKL `mkl_sparse_d_mv` baseline: not available.

GPU: median and min over 50 CUDA-event iterations (warmup 10); CPU: median and min over 10 steady-clock iterations (warmup 3). Kernel time excludes host<->device transfers; `transfer` is the separate H2D+D2H time.

CPU timings were collected on a **2-core Colab VM** (Intel Xeon @ 2.00 GHz, 2 vCPU). The CPU speedups describe that allocation and are not a general claim about OpenMP scaling.

This sweep uses the current ELL implementation, which walks only the real row entries.
